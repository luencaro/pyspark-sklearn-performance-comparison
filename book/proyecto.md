# Proyecto

## Objetivo

Construir un modelo de clasificacion supervisada para predecir si un prestamo termina en:

- `0`: Fully Paid
- `1`: Charged Off

## Dataset

- Fuente: Lending Club Loan Data (2007-2020)
- Volumen: mas de 1.3 millones de registros

## Herramientas principales

- `scikit-learn` para modelado en memoria.
- `PySpark` para procesamiento escalable.
- `LIME` para interpretabilidad local.
